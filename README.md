# WellLovely Loader

Manual map injector for the WellLovely DLL into Minecraft 1.8.9 processes.

## Usage

1. Build or download `WellLovely.dll` from the [WellLovely](https://github.com/pixuszin/WellLovely) repo
2. Place `WellLovely.dll` in the same folder as `Loader.exe`
3. Open Minecraft 1.8.9 (Forge, Badlion, or other client)
4. Run `Loader.exe` as Administrator
5. Select the Java process to inject into

## Compiling

- Visual Studio 2022+ with C++17
- Platform: x64 Release
